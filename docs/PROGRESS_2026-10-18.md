  Prioritas pertama konsistensi CA saat proses terputus, lalu lifecycle, logout,

  yang tidak dapat dijalankan berstatus BELUM_TERUJI, bukan PASS.

## Intent perbaikan CA setelah reproduksi

- Reproduksi OpenSSL terisolasi: SIGKILL setelah signing menyebabkan retry CSR
  membuat dua serial; CRL tetap terbit ketika serial kosong. 2 FAIL/1 PASS pada
  source awal. Audit rinci: AUDIT_HARDENING_2026-10-18.md.
- Tambahkan staging transaksi dan durable manifest roll-forward, validasi relasi
  state serta fault injection sebelum/saat publikasi. Pertahankan root/key/index
  utama dan sejarah revocation; jangan menebak counter. Source dan tes dahulu.

## Intent lifecycle dan logout

- Baseline Linux selesai 163 PASS/1 SKIP (147,09 detik); skip ACL Windows native.
  Semua VM shut off pada pemeriksaan read-only. CA fault tests sedang berjalan.
- Lanjut perbaikan lifecycle yang terverifikasi di source: Linux preflight kosong,
  cleanup setelah up gagal belum membuktikan ownership; daemon tanpa watchdog.
  Tambahkan guard ownership dan watchdog, tes renewal berulang serta cleanup gagal.
- Implementasikan logout karyawan scoped pada token dengan tombstone hash untuk
  retry idempotent, commit invalidasi sebelum penghapusan peer, dan lock yang sama
  dengan verify. Client mempertahankan token ketika server belum mengonfirmasi.
  Uji race logout/renewal serta sesi lain. Tidak melakukan rollout VM saat ini.

## Hasil CA awal dan intent status/readiness

- Baseline 163 PASS/1 SKIP; suite CA/PKI 33 PASS (93,09 detik), mencakup SIGKILL

  Liveness tetap sederhana. Tambahkan ukuran database/log untuk pengamatan admin.
