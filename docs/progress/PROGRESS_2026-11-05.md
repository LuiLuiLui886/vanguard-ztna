## Intent — satu flowchart lengkap

Satukan alur backend/CA, installer, enrollment, admission, akses, renewal,
logout/revoke, recovery dan audit dalam satu diagram Mermaid di satu file.
Periksa terhadap source, validasi diagram dan tautan, update checkpoint/handoff,
lalu push branch feature. Tidak mengubah VM, installer atau aplikasi.

## Hasil

Satu file docs/FLOWCHART_SISTEM_LENGKAP.md berisi tepat satu blok Mermaid yang
menghubungkan seluruh lifecycle. Pemeriksaan source mencakup register/binding,
admission, reconcile/logout dan workflow revoke. Diagram menunjukkan EXE umum
belum lockdown, enam cek sebelum peer, grant per-resource/internet, unknown,
logout offline/pemutusan belum terkonfirmasi, cleanup ownership dan recovery.

Parser Mermaid11.12.0 lulus; pemeriksaan graph memastikan seluruh simpul saling
terhubung dalam satu diagram. Tautan lokal nol rusak. README/manual/halaman
unduhan kini menunjuk flowchart terpadu. HTML manual diregenerasi dari MD.
Lima SVG lama dipertahankan sebagai arsip. Dependensi parser hanya di state privat,
tidak ikut repo. Ini validasi sintaks/struktur; bukan uji visual browser GitHub,
uji Windows, atau perubahan backend. Tidak ada klaim penerimaan fisik baru.
Berikutnya push branch feature dan lanjut preflight kampus sesuai runbook.
