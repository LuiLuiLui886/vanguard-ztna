# Audit bug kandidat internet — 28 Oktober 2026

Audit dimulai dari commit88c92b9 pada branch feature. Cakupan: validasi profil,
urutan renewal client, cleanup Windows, gate internet dan status kesehatan.
Ini audit terbatas, bukan klaim sistem bebas bug. Source diuji di Linux lokal;
seluruh tujuh VM shut off saat audit dan tidak diubah. Hasil native Windows11
sebelumnya tetap untuk paket r8 **sebelum patch audit ini**.

## Temuan terkonfirmasi dan perbaikan

| ID / klasifikasi | File/fungsi dan bukti | Dampak / prioritas | Perbaikan / kriteria selesai |
|---|---|---|---|
| RENEW-GUARD-01 — Bug terbukti | `vanguard/client.py::_connect`; reproduksi events `guard, admit, up, admit, guard, down` ketika pemeriksaan firewall kedua gagal | Lease server sempat diminta/diperpanjang sebelum client menyadari policy tidak terkonfirmasi; P1. Tidak membuktikan bypass enam cek server | Periksa policy sebelum meminta renewal. Regresi harus membuktikan tidak ada admit tambahan saat guard gagal, termasuk sesudah beberapa renewal; cleanup tetap dipanggil |
| PROFILE-TYPE-01 — Bug terbukti | `vanguard/profile.py::validate_profile`; DNS `[16843009]`, DNS campuran dan route `[168296449]` lolos validator; tiga tes penolakan FAIL | Profil salah tipe diterima, lalu join string konfigurasi dapat TypeError; kesalahan baru muncul saat penggunaan; P2 | Wajibkan string pada DNS/route/network; profil salah tipe harus Rejected sejak validasi, profil valid/schema1 tetap diterima |

`ipaddress` menerima sebagian integer sebagai alamat IPv4, tetapi kontrak JSON
profil adalah alamat teks. Guard tambahan mencakup backend/tunnel network agar
tidak ada konversi tipe implisit pada field tersebut. Patch tidak mengubah binding,
private key, CA, handshake WireGuard, atau kewajiban sesi/admission HTTPS.

Pemeriksaan firewall lokal bukan remote attestation. Perubahan urutan mencegah
permintaan renewal sesudah guard yang gagal; tidak menjamin policy tidak bisa
berubah di antara pemeriksaan dan penggunaan, atau langsung mencabut lease lama
ketika transport ke server tidak tersedia. Lease/gate server tetap memiliki batas
waktu dan cleanup tetap memerlukan kepemilikan serta konfirmasi stop.

admission atau bahwa pencabutan izin internet yang sudah diuji gagal.
