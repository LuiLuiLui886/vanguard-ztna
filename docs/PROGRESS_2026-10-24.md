setting/enrollment/admin dan merapikan GitHub menjadi satu/dua branch. Batas
persiapan-only sebelumnya digantikan untuk lingkup ini. Mulai dcc1a85 bersih;

identitas utama dan credential privat. Tidak mengganti jaringan fisik/router.

panduan CA yang ada → CSR client → admin; merge histori relevan ke main dan
hapus hanya branch yang seluruh commit-nya sudah terjangkau, setelah backup Git.
Pertahankan main + satu branch kerja. Tidak force-push atau menghapus histori.
Hasil native, CI, mock dan fisik dicatat terpisah.
